# IaC Scaffold Templates

This directory contains reference patterns for each supported framework. Cline reads these when scaffolding new projects.

## Frameworks

- cdk/: CDK TypeScript project structure patterns
- terraform/: Terraform module structure patterns
- sam/: SAM application patterns
- cfn/: CloudFormation template patterns

These are reference files, not runnable templates. They show Cline the expected structure and conventions for each framework.
